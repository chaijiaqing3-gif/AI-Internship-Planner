## 📌 项目背景

对于缺乏实习经验的大学生来说，求职过程中经常会遇到一个问题：

> **“我到底适合什么岗位？”**

很多学生只能根据自己的专业名称寻找岗位，例如：

- 物联网 → 嵌入式
- 计算机 → 开发
- 市场营销 → 市场
- 英语 → 外贸

但实际求职中，一个人的岗位匹配度并不只由专业决定。

**项目经历、技术能力、AI 工具使用能力、产品思维、个人兴趣以及目标岗位要求**，都会影响最终的职业选择。

因此，我尝试将这一过程转化为一个 AI 产品问题：

> **能否让 AI 综合分析用户的专业、技能、项目经历和求职目标，并给出更加个性化的实习方向建议？**

---

## 💡 产品定位

**AI 实习规划助手**是一款面向大学生求职场景的 AI 辅助决策产品。

用户输入自己的基本信息、专业背景、技能、项目经历及求职目标后，系统通过 LLM 对用户画像进行分析，并结合预设的岗位匹配逻辑生成：

- 🎯 适合的实习方向
- 📊 岗位匹配分析
- 💡 推荐理由
- ⚠️ 当前能力短板
- 📈 后续提升建议

产品的核心并不是简单地“让 AI 推荐岗位”，而是尝试建立：

**用户信息 → 能力分析 → 岗位匹配 → 推荐结果**

这一完整的 AI 产品流程。

---

## 🧩 核心功能

### 01 · 用户画像分析

综合分析用户：

- 专业背景
- 技术技能
- 项目经历
- 实习/实践经历
- 兴趣方向
- 目标岗位

形成基础用户画像。

### 02 · 能力与岗位匹配

通过 LLM 对用户当前能力进行结构化分析，并判断与目标岗位之间的匹配程度。

### 03 · 个性化岗位建议

根据用户画像输出更加具体的实习方向，而不是单纯根据专业进行推荐。

### 04 · 能力差距分析

识别用户当前能力与目标岗位要求之间的差距，并给出针对性的提升建议。

### 05 · Prompt 迭代优化

通过不同用户输入进行测试，对 Prompt、模型参数及 Workflow 逻辑进行持续调整，提高输出的针对性和稳定性。
